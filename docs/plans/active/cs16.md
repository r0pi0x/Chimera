# Plan: Counter-Strike 1.6 on Chimera

Started 2026-11-24 (made by tools/new-game; docs/CONTRIBUTING-GAMES.md).
CS 1.6 is the first game of the GoldSrc family: its plan (the install,
the formats, the milestones, the specs, the risks) is
[goldsrc.md](goldsrc.md), whose status table is the one kept up to date.
This file keeps what is CS 1.6's own: the install's notes and its log.

## The install

Counter-Strike is Steam app 10 (the client, `steamapps/common/Half-Life/`)
or the Half-Life Dedicated Server, app 90 with `mod cstrike` (SteamCMD,
anonymous). The install root holds `cstrike/` and `valve/`; it is found by
`$CHIMERA_CS16_ROOT`, `[games.cs16] path` in chimera.local.toml or (from
M0) Steam's libraries. Details in [goldsrc.md](goldsrc.md), section 2.
